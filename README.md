🎬 Dorama Box

O Dorama Box é uma aplicação web desenvolvida com HTML e CSS que apresenta uma curadoria de doramas organizados por categorias, com foco em uma experiência visual simples, limpa e intuitiva.

📖 Descrição

A proposta do projeto é exibir doramas populares por meio de uma interface estruturada em seções, permitindo ao usuário navegar facilmente entre diferentes gêneros e visualizar sinopses detalhadas.

O sistema é dividido em três categorias principais:

💖 Romance
🎭 Drama
👻 Sobrenatural

Cada categoria contém cards com:

Título do dorama
Sinopse
Imagem ilustrativa
🧠 Aprendizados

Durante o desenvolvimento deste projeto, foram praticados conceitos importantes de front-end:

Estruturação semântica com HTML5
Organização de layout com containers
Uso de navegação por âncoras (#id)
Criação de componentes visuais (cards)
Separação de responsabilidades (HTML + CSS)
⚙️ Funcionalidades
Menu de navegação entre seções
Layout em formato de cards
Organização por categorias
Reprodução de áudio de fundo
Conteúdo estático otimizado para leitura
